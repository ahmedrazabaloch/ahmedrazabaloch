## 👋 About Me

I’m a **Full-Stack JavaScript Developer** focused on building production-ready web applications and backend systems for real-world products.

My work spans **frontend architecture, API development, databases, CMS platforms, commerce integrations, and AI-powered systems**. I enjoy turning product requirements into maintainable software with clear boundaries, reliable APIs, strong data integrity, and practical deployment workflows.

I primarily work with the **React / Next.js ecosystem** on the frontend and **Node.js / NestJS** on the backend, with hands-on experience across **PostgreSQL, Prisma, MongoDB, Payload CMS, Shopify, and third-party AI APIs**.

### What I Care About

- 🏗️ **Maintainable architecture** — clear domain boundaries, reusable modules, and code that can evolve with the product.
- 🔌 **Reliable backend systems** — well-defined APIs, validation, authentication, authorization, data integrity, and integrations.
- 🤖 **Practical AI integration** — using LLMs where they create measurable product value rather than adding AI for the sake of it.
- 🚀 **Production delivery** — building systems that can move from an idea or MVP into a reliable, deployable product.
